# Chiosco Belvedere

Sito web responsive per Chiosco Belvedere, ristorante di cucina mediterranea ad Albenga, Liguria.

## Avvio locale

```bash
npm install
npm run dev
```

Per creare il bundle di produzione:

```bash
npm run build
```

Il progetto usa React, Vite e `lucide-react`. Le immagini della galleria arrivano da Unsplash; la prenotazione è una richiesta lato client con conferma visiva.
